# 鹈鹕骑士 · Pelican Knight

《鹈鹕骑士》是一款单文件 HTML5 地牢射击小游戏。

鹈鹕骑士的水下鱼干仓库被盗，于是骑上单车、带上伙伴，深入七座风格迥异的海洋地牢：潮湿洞窟、珊瑚浅滩、冰封峡湾、熔岩蟹窟、沉船墓场、深渊王庭，直至王座终焉。骑单车穿梭房间、拾取武器与技能、招唤游侠伙伴、解救囚笼里的队友、在小吃摊补充能量，把鱼干统统抢回来。

## 操作

- `WASD` / 方向键：骑车
- `空格` / `J`：射击（自动瞄准）
- `Shift` / `K`：冲刺
- `C`：技能
- `Q`：切换主副手
- `E`：拾取 / 购买 / 锻造
- `M`：音乐开关
- `P`：暂停

## 在线试玩

1. 进入本仓库 **Settings → Pages**。
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/(root)`。
3. 保存后稍等 1–2 分钟，访问：  
   `https://OenotheraFrequency.github.io/pelican-knight/pelican-knight.html`

## 本地运行

直接用浏览器打开 `pelican-knight.html` 即可。
